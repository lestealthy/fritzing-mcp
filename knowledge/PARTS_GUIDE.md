# Parts Guide

- Part IDs are Fritzing module IDs (e.g. `arduino_Uno_Rev3(fix)`, `DS18B20_fixed`, `ResistorModuleID`).
- Always search before using a part; never invent IDs.
- Trust levels: OFFICIAL, VERIFIED, COMMUNITY, GENERATED, UNKNOWN, REJECTED.
- OFFICIAL/VERIFIED may be placed. COMMUNITY requires administrator policy. GENERATED requires validation. REJECTED/UNKNOWN are denied.
